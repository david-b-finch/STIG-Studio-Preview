STIG Studio · Public test build

STIG Studio v0.7.1

Experimental preview · Snapshot build · Not a validated release

An offline-first, browser-based tool for viewing and editing STIG checklists, comparing assessments, and combining asset checklists. This public preview is for usability feedback and controlled testing.

EXPERIMENTAL — DO NOT USE FOR OPERATIONAL ASSESSMENTS

This build has known or suspected data-integrity risks affecting conversion, comparison, and combined exports. It has not passed a full regression or interoperability test suite. Do not rely on the exported results for authorization, compliance, or production reporting.

Use synthetic or fully sanitized test files only. Do not load classified, controlled, sensitive, or actual system assessment data into this public test deployment.

Launch experimental preview → Report an issue

What to try

  • Open synthetic CKLB or CKL files.
  • Change a test rule's status, comments, or finding details.
  • Save the file and verify the exported data independently.
  • Test comparisons, advanced filters, and asset combining.
  • Test in Firefox and Chromium-based browsers.

Start with the synthetic example checklist and the comparison reference.

Give useful feedback

  • Specify browser and version.
  • Describe the exact steps needed to reproduce the problem.
  • Explain expected behavior versus actual behavior.
  • Attach only synthetic or sanitized sample data.
  • Indicate whether saved files re-open successfully.

Feedback is collected through public GitHub Issues; do not post sensitive data.

Privacy and local processing

Source inspection indicates that checklist parsing and export occur in your browser without an application server or intentional checklist uploads. This is not an independent security audit.

GitHub may process ordinary site-visitor information. Files you save are downloaded through your browser; unsaved application state is not durable.
