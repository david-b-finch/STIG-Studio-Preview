# Reference archive inputs

Original DISA STIG reference ZIP/XML files supplied in the development folder
`Test-Docs-20261017`, copied without changes for import/update testing.

These are reference data, not completed assessments. Each Apache ZIP has both
Site and Server STIGs. `manifest.json` records original filenames, sizes and
SHA-256 hashes. The readable download page is `index.html`.
