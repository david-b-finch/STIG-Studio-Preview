Working an Assessment

Choose a rule, read its Check Content, enter Finding Details and then Comments, and choose its assessment status. Switch between Tabs and expandable Sections beside the STIG information. Drag the horizontal divider to give reading or editing more room.

Search and quick filters narrow the rule list. Advanced Filters supports exclusions and field-specific searches. Clear Filters restores every rule.

Enable Select Rules for bulk edits and selected exports. Bulk changes have one undo step; later individual edits are retained.

With a rule focused: 1 / N Not a Finding, 2 / O Open, 3 / X Not Applicable, 4 / R Not Reviewed. Letter shortcuts work in either case. Up / Down moves between rules; Alt+Right / Left also moves through filtered rules. Typing in editors and search does not change statuses. Ctrl/Command+S saves the current CKLB; add Shift to download a workspace.

Save CKLB downloads a complete assessment. Export / More offers reports, Viewer formats, workspaces, and Save All. Browser recovery is optional under File → Workspace / Recovery.

Browser Autosave & Recovery

Working assessments are saved in this browser for recovery. CKLB and Workspace downloads remain your file backups. The separate STIG Library is saved through Export Library.

Import Assessment

Import selected assessment fields and source rules, including matches hidden by checklist filters. Choose Replace, Append, or Keep for text. Blank replacement text clears existing text. Current STIG content, IDs, and asset information are retained.

Only exact rule IDs within the same STIG are matched. Known version/release differences and ambiguous matches are skipped. No STIGs or rules are added.
